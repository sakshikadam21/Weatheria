# 🌦️ Weatheria
## Your Personal Real-Time Weather Companion

Weatheria is a modern, responsive, and feature-rich weather web application built using **HTML, CSS, and Vanilla JavaScript**.  
It delivers accurate real-time weather insights with a clean UI, smooth animations, and mobile-first design.  

Designed to be **interview-ready, deployment-ready, and production-quality**.

---

## Live Demo
👉*(https://weatheriaonline.vercel.app/)*

---

## ✨ Feature Stack

✅ Live Weather (OpenWeather API)  
✅ Auto Location Detection  
✅ Dynamic Weather Themes  
✅ Sunrise / Sunset Progress Bar  
✅ Favorite Cities  
✅ Recent Searches  
✅ Air Quality Index (AQI)  
✅ 5-Day Forecast  
✅ Mobile Responsive UI  

---

## 🧠 Advanced Highlights

- Weather-based dynamic background effects  
- Emoji-driven weather representation  
- Persistent favorites & recent searches using LocalStorage  
- Air Quality Index with health-based indicators  
- Optimized API handling for performance  
- Clean, professional UI suitable for interviews  
- No frameworks — pure JavaScript  

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6)  
- **API:** OpenWeatherMap API  
- **Storage:** Browser LocalStorage  
- **Design:** Mobile-first & responsive
